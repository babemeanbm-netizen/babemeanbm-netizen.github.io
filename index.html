Motor Monitor

Motor Monitor is a private monitoring tool that runs on an industrial edge computer. It records motor sensor data (vibration, current, temperature) and uploads daily CSV files to the owner's own Google Drive.

Privacy Policy

  • Google data accessed: the app uses only the drive.file scope. It can see and change only the files it creates itself. It cannot read any other file in your Google Drive.
  • How the data is used: only to upload the machine's own sensor data files to the owner's Drive.
  • Sharing: no Google user data is sold, shared with third parties, or used for advertising.
  • Storage: the access token stays only on the owner's computer and edge device. It is never sent to any other server.
  • Revoking access: remove the app at any time at myaccount.google.com/permissions.

นโยบายความเป็นส่วนตัว (ภาษาไทย)

  • แอปขอสิทธิ์ drive.file เท่านั้น เข้าถึงได้เฉพาะไฟล์ที่แอปสร้างเอง และอ่านไฟล์อื่นใน Google Drive ไม่ได้
  • ใช้สิทธิ์นี้เพื่ออัปโหลดไฟล์ข้อมูลเซ็นเซอร์ของเครื่องขึ้น Drive ของเจ้าของเท่านั้น
  • ไม่ขาย ไม่แชร์ข้อมูลให้บุคคลอื่น และไม่ใช้ข้อมูลเพื่อโฆษณา
  • token เก็บอยู่บนเครื่องของเจ้าของเท่านั้น และไม่ถูกส่งไปที่เซิร์ฟเวอร์อื่น
  • ยกเลิกสิทธิ์ได้ทุกเมื่อที่ myaccount.google.com/permissions
